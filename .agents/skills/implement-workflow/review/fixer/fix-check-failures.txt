OPERATIONAL FAILURE FIX

Fix only the exact check, test, lint, build, conflict, or merge failure appended by the top-level manager. Read the command, status, URL, head SHA, and output. Make the smallest root-compatible correction supported by that evidence. If the failure is infrastructure-only or outside scope, report that without changing unrelated code.

Use focused tests while coding. Perform the full shared completion phase only after the correction is implemented. Commit and push the green result, then report the exact SHA, push result, focused evidence, and final command results.
